About

Kana Learner is a free, independent Japanese study tool for people who want a clean, no-nonsense way to learn hiragana and katakana.

It started as a personal project — an existing tool I relied on changed its interface, so I built a replacement. The result is a focused app: an interactive kana chart with romaji, column-based selection, and a flashcard study mode with score and time tracking.

Everything is free. No account required. No ads. Works on desktop and mobile.
